# Atención de tickets

Herramientas personales para organizar el día de trabajo en infraestructura y registrar las atenciones en Jira.

| Carpeta | Contenido |
|---|---|
| `organizador-atenciones/` | Herramienta local: accesos rápidos, atenciones, bitácora con correos y capturas, foco. Guía de uso en su `README.md`. |
| `agente-copilot/` | Agente y skills de GitHub Copilot (`.github`) que preparan los registros de Jira. |
| `docs/diseno.md` | Decisiones y acuerdos del diseño. |
| `CLAUDE.md` | Contexto para Claude Code. |

Este repositorio no contiene datos. Los datos viven en dos carpetas de OneDrive indicadas con variables de entorno (ver `organizador-atenciones/README.md`).
